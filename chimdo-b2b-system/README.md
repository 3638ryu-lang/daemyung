# 한국침도교육원 B2B(도매) 판매관리 시스템

한국침도교육원이 중간 도매상 **워니리스트**에 침도를 공급하는 것을 관리하는
**B2B 전용** 프로그램입니다. (워니리스트가 다시 공급하는 안진메디팜/이메디샾/인티그레이션은
직접 청구 대상이 아니라, 주문마다 "최종 재판매처"로 참고 기록만 됩니다.)

> ⚠️ **이 시스템은 B2C(한의원 대상) 시스템과 완전히 다른 화면/저장소를 쓰지만,
> 재고(Products 시트의 재고 수량)는 B2C와 하나로 공유합니다.** 한의원에 판매(B2C)한
> 만큼도, 워니리스트에 공급(B2B)한 만큼도 **같은 재고 숫자**에서 함께 차감됩니다.
> 그래서 이 시스템은 새 구글 시트를 만들지 않고, **B2C 시스템이 쓰고 있는 바로 그
> 구글 시트/Apps Script**를 그대로 사용합니다.

## 1. 이 프로그램의 구조

```
[B2C 주문 페이지/관리자]  ↘
                          [하나의 Google Apps Script + 구글 시트] ← 재고 공유
[B2B 관리자(이 프로그램)] ↗
```

- `admin.html` : B2B 관리자 전용 화면입니다. **공개 주문 페이지가 없습니다** — 워니리스트에서
  전화/메일로 받은 주문을 관리자가 이 화면에서 직접 입력하는 구조입니다.
- `statement.html` : 거래처(워니리스트)별 정산서를 인쇄/PDF저장하는 화면입니다.
- `assets/` : 공용 디자인(css)과 통신 코드(js) 입니다.
- 이 저장소에는 `apps-script` 폴더가 없습니다 — **B2C 시스템(`chimdo-order-system`
  저장소)의 `apps-script/Code.gs`를 그대로 함께 사용**하기 때문입니다.

## 2. 설치 방법

이미 B2C 시스템을 설치·운영 중이라는 전제 하에 진행합니다 (아직 B2C를 설치하지
않으셨다면 `chimdo-order-system`의 README부터 먼저 진행해주세요).

### 2-1. 기존 Apps Script 코드를 최신 버전으로 교체 (B2B 기능 포함)

1. B2C 시스템에 연결된 구글 시트에서 **확장 프로그램 → Apps Script** 열기
2. `Code.gs` 내용을 전부 지우고, 아래 최신 코드로 교체 (B2B용 함수/시트 정의가
   추가된 버전입니다):
   👉 https://raw.githubusercontent.com/3638ryu-lang/chimdo-order-system/main/apps-script/Code.gs
3. 저장(💾)
4. 함수 선택 드롭다운에서 **`initializeSheets`** 를 다시 실행합니다.
   - ⚠️ 이미 B2C를 쓰고 계셔도 **안전합니다** — 기존 `Products`/`Customers`/`Orders`/
     `OrderItems`/`Config` 시트는 그대로 두고, B2B에 필요한 `Distributors`,
     `B2BOrders`, `B2BOrderItems` 탭만 새로 추가합니다. `Distributors` 탭에는
     "워니리스트" 거래처가 자동으로 한 줄 등록됩니다.
5. **`Products` 시트에 `WholesalePrice`(도매가) 열이 새로 필요합니다.** 이미
   제품을 등록해두셨다면(예: 3540, 4030 등), `Products` 시트 **맨 오른쪽 빈 열**에
   `WholesalePrice`라는 헤더를 추가하고, 각 제품의 도매가를 입력해주세요.
   (B2B 관리자 페이지의 "재고 관리" 탭에서도 나중에 입력/수정할 수 있습니다.)
6. Apps Script 편집기 우측 상단 **배포 → 배포 관리** → 연필(✏️) 아이콘 → **새 버전**
   선택 → **배포**. (URL은 기존과 동일하게 유지됩니다.)

### 2-2. 이 저장소(B2B 프론트엔드) 배포하기

1. `assets/config.js` 를 엽니다. `API_URL` 값이 **B2C 시스템의 config.js와 동일한
   값**으로 이미 채워져 있는지 확인해주세요 (다르면 B2C의 값을 그대로 복사해오세요).
2. 이 저장소를 GitHub에 올리고 (아직 저장소가 없다면 github.com/new 에서
   `chimdo-b2b-system` 같은 이름으로 새로 만들어주세요), **Settings → Pages**에서
   Source를 `Deploy from a branch`, Branch를 `main`/`/(root)`로 설정하면
   `https://<계정>.github.io/chimdo-b2b-system/admin.html` 형태의 주소가 생깁니다.

## 3. 기본 사용법

### 제품 도매가 등록
1. `admin.html` 접속 후 비밀번호로 로그인합니다 (B2C와 동일한 비밀번호입니다 —
   같은 구글 시트의 `Config` 탭을 함께 씁니다).
2. **재고 관리** 탭에서 각 제품의 **도매가(WholesalePrice)**를 입력/수정합니다.
   - 제품 자체(코드/규격)는 보통 B2C 관리자 페이지에서 먼저 등록해두는 것을
     권장합니다. 여기서는 주로 도매가와 재고만 확인/조정합니다.
   - 재고는 B2C와 완전히 같은 숫자입니다. 여기서 +1/-1로 조정하거나 "수정"으로
     직접 입력하면 B2C 쪽 재고도 함께 바뀝니다.

### 거래처(워니리스트) 등록
- **거래처 관리** 탭에서 "워니리스트"가 이미 한 줄 등록되어 있을 것입니다
  (initializeSheets 실행 시 자동 등록). 담당자/연락처 등 정보를 채워 넣어주세요.
- 추후 다른 도매 거래처가 생기면 같은 방식으로 추가 등록할 수 있습니다.

### 주문 입력
1. **주문 접수/관리** 탭 맨 위 "새 주문 입력"에서 거래처(워니리스트)를 선택합니다.
2. **최종 재판매처**(안진메디팜/이메디샾/인티그레이션/워니리스트 자체/기타)를
   선택합니다 — 이건 참고 기록일 뿐, 청구는 항상 선택한 거래처(워니리스트) 기준입니다.
3. 제품과 박스 수량을 입력하고 **주문 등록**을 누릅니다.

### 주문 처리 (재고는 "출고" 시점에 차감되며, B2C와 공유됩니다)
- 아래쪽 "주문 목록"에서 상태를 접수 → 확인중 → 배송중 → 완료로 변경합니다.
- **배송중/완료로 처음 바뀌는 시점에 재고가 차감**됩니다 — 이때 B2C가 쓰는 것과
  같은 재고 숫자가 줄어듭니다. 재고가 부족하면 출고 처리가 막힙니다.
- 취소 시, 이미 출고 처리된 주문이었다면 재고가 자동 복원됩니다.

### 매출/기부금 통계, 거래처별 정산서
- B2C와 동일한 방식입니다. **매출·기부금 통계** 탭에서 기간별 매출·기부금·제품별
  판매 현황을 확인하고, **거래처 관리** 탭 하단에서 거래처별 정산서를 인쇄/PDF로
  저장할 수 있습니다. (모두 실제 출고된 주문만 집계됩니다.)

## 4. 자주 묻는 질문

**Q. B2C 재고와 B2B 재고가 진짜 같은 건가요? 실수로 헷갈려서 이중 판매되지 않나요?**
A. 네, 정말 같은 숫자입니다. B2C에서 출고 처리하면 B2B 화면에도, B2B에서 출고 처리하면
   B2C 화면에도 즉시 같은 재고 수량이 반영됩니다. 같은 실물 재고를 두 채널이 나눠
   쓰는 구조이므로, 이중 판매(오버셀) 걱정 없이 하나의 숫자만 관리하면 됩니다.

**Q. 안진메디팜/이메디샾/인티그레이션에 개별적으로 청구서를 보내고 싶어요.**
A. 지금은 이 세 곳을 별도 거래처로 청구하지 않고, 워니리스트 앞으로만 정산서가
   나갑니다. 만약 나중에 이 세 곳에도 직접 개별 정산이 필요해지면, 이들을 별도
   거래처로 등록하고 주문을 나눠 입력하는 방식으로 확장할 수 있으니 말씀해주세요.

**Q. 도매가도 거래처별로 다르게 받고 싶어요 (예: 워니리스트 외 다른 도매상이 생기면).**
A. 지금은 제품마다 도매가 1개만 있습니다. 거래처별로 협상 단가를 다르게 적용하려면
   추가 개발이 필요하니 말씀해주세요.
