# 한국침도교육원 침도 주문관리 시스템 (B2C)

**한국침도교육원** 이름으로 **한의원(B2C) 대상**으로 침도(제품)를 주문받고, 재고와
거래처를 관리하고, 매출과 **학회 기부금**을 자동으로 계산해주는 독립형 웹 프로그램입니다.

> 이 폴더는 이 저장소의 다른 파일(병원 홈페이지)과 **완전히 별개로 작동**합니다.
> 병원 홈페이지의 어떤 파일도 참조하지 않으며, 원하는 이름/디자인으로 자유롭게 바꿔 다른 곳에
> 그대로 옮겨서 사용하셔도 됩니다.

> 📦 **B2B(도매상 대상) 판매**는 별도 저장소인 `chimdo-b2b-system`에서 관리합니다.
> 화면은 완전히 분리되어 있지만, **재고(Products 시트)는 이 시스템과 하나로 공유**합니다 —
> 이 저장소의 `apps-script/Code.gs`에 B2B용 함수/시트 정의가 함께 들어있습니다
> (`Distributors`/`B2BOrders`/`B2BOrderItems` 탭, `Products`의 `WholesalePrice` 열).
> 자세한 내용은 `chimdo-b2b-system`의 README를 참고하세요.

## 1. 이 프로그램의 구조 (초보자를 위한 설명)

이 프로그램은 서버(백엔드)를 별도로 구축하지 않고, 이미 사용하고 계신 **구글 시트**를
데이터 저장소로 그대로 사용합니다. 대신 구글 시트와 웹페이지 사이를 연결해주는
**Google Apps Script**라는 구글의 무료 기능을 "서버" 역할로 사용합니다.

```
[고객이 보는 주문 페이지]  →  [Google Apps Script (무료 API 서버)]  →  [구글 시트 (데이터 저장)]
[관리자가 보는 관리 페이지] ↗
```

- `order.html` : 고객(거래처)이 침도를 주문하는 화면입니다. 회원/비회원을 선택해서 주문합니다.
- `admin.html` : 관리자가 로그인해서 주문/재고/거래처/매출을 관리하는 화면입니다.
- `statement.html` : 관리자 페이지에서 여는, 거래처별 정산서를 인쇄/PDF저장하는 화면입니다.
- `apps-script/Code.gs` : 구글 시트와 연결되는 서버 코드입니다.
- `assets/` : 화면들이 공통으로 쓰는 디자인(css)과 통신 코드(js) 입니다.

## 2. 설치 방법 (한 번만 하면 됩니다)

### 2-1. 구글 시트 만들기

1. [Google Sheets](https://sheets.new) 에서 새 스프레드시트를 만듭니다.
2. 이름을 예를 들어 "한국침도교육원 주문관리 DB" 로 정합니다.
3. 시트 안의 탭(Products, Customers, Orders 등)은 **직접 만들 필요 없습니다.**
   아래 2-2 단계에서 자동으로 생성됩니다.

### 2-2. Apps Script 서버 배포하기

1. 방금 만든 구글 시트에서 상단 메뉴 **확장 프로그램 → Apps Script** 를 클릭합니다.
2. 기본으로 열려있는 `Code.gs` 파일의 내용을 모두 지우고, 이 저장소의
   `chimdo-order-system/apps-script/Code.gs` 파일 내용을 전부 복사해서 붙여넣습니다.
3. 상단의 **저장(디스크 모양 아이콘)** 을 클릭합니다.
4. 함수 선택 드롭다운에서 `initializeSheets` 를 선택하고 **실행(▶)** 버튼을 누릅니다.
   - 처음 실행 시 "권한 승인" 화면이 뜨면, 본인 구글 계정으로 **허용**해주세요.
   - 실행이 끝나면 구글 시트로 돌아가서 `Products`, `Customers`, `Orders`, `OrderItems`,
     `Config` 탭이 자동으로 생성된 것을 확인할 수 있습니다.
5. `Config` 탭에서 `AdminPassword` 값을 **원하는 관리자 비밀번호로 반드시 변경**하세요.
   (기본값 `changeme123` 을 그대로 두면 누구나 관리자 화면에 들어올 수 있습니다.)
6. 다시 Apps Script 편집기로 돌아가서 우측 상단 **배포 → 새 배포** 를 클릭합니다.
7. 유형 선택에서 톱니바퀴(⚙) 아이콘을 누르고 **웹 앱**을 선택합니다.
8. 아래와 같이 설정합니다.
   - 실행할 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (이래야 주문 페이지에서 로그인 없이 접근 가능)
9. **배포**를 누르면 `https://script.google.com/macros/s/....../exec` 형태의
   **웹 앱 URL**이 발급됩니다. 이 URL을 복사해두세요.

> 이후 `Code.gs` 코드를 수정했다면, "배포 → 배포 관리 → 수정(연필 아이콘) → 새 버전 → 배포"
> 순서로 다시 배포해야 변경 사항이 실제 서비스에 반영됩니다.

### 2-3. 웹페이지에 서버 주소 연결하기

1. `chimdo-order-system/assets/config.js` 파일을 엽니다.
2. `API_URL` 값에 2-2 단계에서 복사한 웹 앱 URL을 붙여넣습니다.
3. `SITE_NAME` 값은 화면 상단에 표시할 판매 주체(브랜드) 이름입니다. 기본값은
   `한국침도교육원`으로 설정되어 있으며, 필요하면 다른 이름으로 바꾸셔도 됩니다.

```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/여기에_본인의_URL/exec',
  SITE_NAME: '한국침도교육원'
};
```

### 2-4. 웹페이지 열기 / 배포하기

- **가장 간단한 방법**: `order.html`, `admin.html` 파일을 더블클릭해서 로컬에서 바로 열어봐도
  잘 동작합니다 (인터넷 연결만 있으면 됩니다).
- **다른 사람도 접속하게 하려면**: 이 `chimdo-order-system` 폴더를 GitHub Pages, Netlify,
  Vercel 같은 무료 정적 호스팅 서비스에 올리면 누구나 인터넷 주소로 접속할 수 있습니다.
  (병원 홈페이지와 완전히 다른 별도의 저장소/주소에 올리셔도 무방합니다.)

## 3. 기본 사용법

### 제품(재고) 등록하기
1. `admin.html` 접속 후 비밀번호로 로그인합니다.
2. **재고 관리** 탭에서 제품명, **회원가/비회원가**(박스당), 초기 재고, **박스당 기부금**을
   입력하고 저장합니다.
   - 회원으로 주문하면 회원가, 비회원으로 주문하면 비회원가가 자동으로 적용됩니다.
   - "박스당 기부금"은 이 제품이 1박스 팔릴 때마다 학회에 기부할 금액입니다.

**처음 설치 시 실제 판매 제품을 한 번에 등록하려면**: Apps Script 편집기에서 함수 선택
드롭다운에 `setupRealProducts`를 선택하고 실행(▶)하면, `apps-script/Code.gs`에 미리 적어둔
제품 목록으로 Products 시트를 한 번에 채울 수 있습니다 (제품 코드/가격을 바꾸고 싶으면
Code.gs의 `setupRealProducts` 함수 안 목록을 직접 수정한 뒤 실행하세요). 이미 등록된 제품이
있는 상태에서 실행하면 **기존 내용이 전부 지워지고 새로 채워지니** 주의해주세요.

### 거래처 등록하기 (회원)
1. **거래처 관리** 탭에서 구분을 "회원"으로 선택하고 거래처 정보를 입력 후 저장합니다.
   - 비회원은 별도로 등록하지 않아도, 주문 페이지에서 비회원 주문이 들어오면 자동으로
     "비회원"으로 거래처 목록에 기록됩니다.

### 주문 받기
- 고객(거래처)은 `order.html` 에서 회원/비회원을 선택해 직접 주문합니다.
- 또는 관리자가 전화로 받은 주문을 대신 `order.html`에서 입력해도 됩니다.

### 주문 처리하기 (재고는 "출고" 시점에 차감됩니다)
- **주문 관리** 탭에서 주문 상태를 접수 → 확인중 → 배송중 → 완료 순서로 변경합니다.
- ⚠️ **재고는 주문이 들어온 시점이 아니라, 상태를 "배송중" 또는 "완료"로 처음 바꾸는 시점
  (= 실제 출고 시점)에 차감됩니다.** 그 전까지(접수/확인중)는 재고 숫자가 줄지 않습니다.
  - 재고가 부족하면 "배송중/완료"로 바꿀 수 없고, 부족하다는 안내 메시지가 뜹니다.
  - 목록에서 각 주문마다 "✔ 출고완료(재고 차감됨)" / "출고 전(재고 미차감)" 표시로 현재 상태를
    바로 확인할 수 있습니다.
- 주문을 "취소"로 변경하면, **이미 출고 처리(재고 차감)된 주문이었을 경우에만** 재고가 자동으로
  복원됩니다. 아직 출고 전(접수/확인중)이었던 주문을 취소할 때는 애초에 차감된 재고가 없으므로
  복원할 것도 없습니다.

### 매출 / 학회 기부금 확인하기
- **매출·기부금 통계** 탭에서 기간을 선택하면
  - 총 매출, 총 판매 박스 수, **학회 기부금 합계**
  - 회원/비회원별 매출
  - 제품별 판매량·매출·기부금
  이 자동으로 계산되어 보여집니다.
- 매출/기부금은 **실제로 출고(배송중/완료 처리)된 주문만** 집계합니다. 아직 출고 전인
  접수/확인중 주문이나, 취소된 주문은 집계에서 빠집니다. (회계상 "출고 = 매출 확정" 기준)
- 기부금 계산 방식: **주문 시점의 (제품별 박스당 기부금) × (판매 박스 수)** 를 모두 더한 금액입니다.
  나중에 제품의 기부금 단가를 바꾸더라도, 이미 발생한 과거 주문의 기부금 금액에는 영향을 주지 않습니다.

### 거래처별 정산서(PDF) 발급하기
1. **거래처 관리** 탭 맨 아래 "거래처별 정산서 발급" 카드에서 거래처, 시작일, 종료일을
   선택하고 **"정산서 보기 / 인쇄"** 버튼을 누릅니다.
2. 새 창(`statement.html`)에 해당 거래처의 **실제 출고된** 주문만 정리된 정산서가 표로
   나타납니다. (출고 전 주문·취소된 주문은 정산서에 포함되지 않습니다)
3. 새 창 우측 상단의 **"인쇄 / PDF로 저장"** 버튼을 누르면 브라우저 인쇄 창이 뜹니다.
   인쇄 대상(프린터)을 **"PDF로 저장"**으로 선택하면 정산서가 PDF 파일로 저장됩니다.
   - 한글이 포함된 PDF를 안정적으로 만들기 위해 별도 PDF 라이브러리 대신 브라우저 자체의
     인쇄 기능을 사용하는 방식입니다. 클릭이 한 번 더 필요하지만, 글자가 깨지지 않고
     인쇄 품질도 가장 좋습니다.
4. 같은 연락처로 반복 주문한 **비회원**도 자동으로 같은 거래처로 묶여서 정산서에 함께
   집계됩니다 (전화번호 기준으로 동일 인물 여부를 판단합니다).

## 4. 자주 묻는 질문

**Q. 구글 시트를 열어서 직접 데이터를 수정해도 되나요?**
A. 네, 가능합니다. 다만 `Orders`/`OrderItems`의 금액·기부금 값은 주문 시점에 자동 계산되어
   저장된 값이므로, 시트에서 직접 수정하면 화면에 표시되는 통계와 차이가 날 수 있습니다.

**Q. 관리자 비밀번호를 잊어버렸어요.**
A. 구글 시트의 `Config` 탭에서 `AdminPassword` 값을 직접 열어서 확인하거나 변경할 수 있습니다.

**Q. 여러 명이 동시에 관리자 화면을 써도 되나요?**
A. 네, 가능합니다. 각자 로그인하면 각자의 로그인은 8시간 동안 유지됩니다.

**Q. 회원가/비회원가 말고, 회원 등급(VIP 등)별로 가격을 더 세분화하고 싶어요.**
A. 현재는 "회원가"와 "비회원가" 두 단계만 지원합니다. 등급을 더 세분화(예: 일반회원/VIP회원)
   하려면 추가 개발이 필요하니 말씀해주세요.

**Q. 이미 `initializeSheets`를 실행해서 구글 시트를 만들어 둔 상태인데, 새로 받은
   `Code.gs`(출고 시점 재고차감 / 정산서 기능 포함)를 반영하려면 어떻게 하나요?**
A. `initializeSheets`는 시트가 이미 있으면 헤더를 다시 만들지 않으므로, 기존 `Orders` 탭에
   `StockDeducted` 열이 자동으로 추가되지 않습니다. 다음 두 가지 중 하나로 처리해주세요.
   - (아직 실제 주문 데이터가 없다면) `Orders`, `OrderItems` 탭을 삭제한 뒤 Apps Script
     편집기에서 `initializeSheets`를 다시 실행 — 가장 간단합니다.
   - (이미 주문 데이터가 쌓였다면) `Orders` 탭의 맨 오른쪽에 `StockDeducted`라는 이름의 열을
     직접 추가하고, 기존 주문 행들은 이미 재고가 차감된 상태였을 테니 `배송중`/`완료`
     상태인 행에는 `TRUE`를, 그 외에는 `FALSE`를 채워 넣어주세요.
   - 두 경우 모두, 코드를 수정한 뒤에는 "배포 → 배포 관리 → 새 버전 → 배포"로 다시
     배포해야 웹 앱에 반영됩니다 (2-2단계 참고).

**Q. B2B(도매) 시스템을 연결했는데 Products 시트에 `WholesalePrice` 열이 없다고 나와요.**
A. 이미 제품을 등록해두신 상태에서 B2B 기능을 나중에 추가하면, `Products` 시트에
   `WholesalePrice`(도매가) 열이 자동으로 생기지 않습니다. `Products` 시트 맨
   오른쪽 빈 열에 `WholesalePrice`라는 헤더를 직접 추가하고, 제품별 도매가를
   입력해주세요. 자세한 내용은 `chimdo-b2b-system`의 README를 참고하세요.
